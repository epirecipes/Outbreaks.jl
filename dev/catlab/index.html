Categorical Aggregation

Outbreaks.jl includes an optional Catlab.jl extension for representing line lists categorically and aggregating them across temporal and categorical scales. Load Catlab alongside Outbreaks to activate these methods:

using Outbreaks, Catlab

ll = LineListACSet(measles_hagelloch_1861(), onset = :date_of_prodrome)
weekly = ll ↓ Outbreaks.Week
counts = ♯(weekly)
stratified = ♯(ll, Outbreaks.Week ⊗ Class(:class))
monthly = weekly ↓ Outbreaks.Month
Note

Day, Week, Month, and Year are temporal scales exported by Outbreaks.jl. If Dates is also loaded, qualify them as Outbreaks.Week, Outbreaks.Month, and so on to avoid ambiguity with Dates.Week.

Outbreaks.TemporalScale — Type
TemporalScale

Represents a temporal aggregation resolution (Day, Week, Month, Year). Each scale defines a binning morphism from finer to coarser time.

Outbreaks.CategoricalScale — Type
CategoricalScale(col::Symbol)

Stratification by a categorical column (e.g., district, sex, age group).

Outbreaks.ProductScale — Type
ProductScale

Tensor product of scales for joint stratification. Created via ⊗, e.g. Week ⊗ Class(:district).

Outbreaks.BucketedCases — Type
BucketedCases

Result of categorical aggregation before decategorification. Preserves fiber structure: for each bucket, knows which cases are in it (not just how many). The bin_map field holds the FinFunction from cases to bins once the Catlab extension is loaded.

Outbreaks.LineListACSetWrapper — Type
LineListACSetWrapper

Wraps a Catlab ACSet with metadata for ergonomic categorical operations.

Outbreaks.LineListACSet — Function
LineListACSet(df::DataFrame; onset, location=nothing, age=nothing, outcome=nothing)

Convert a DataFrame into a categorical ACSet. Requires Catlab.jl.

Example

using Outbreaks, Catlab
ll = LineListACSet(measles_hagelloch_1861(), onset=:date_of_prodrome, location=:class)
Outbreaks.EpiCurveACSet — Function
EpiCurveACSet(df::DataFrame; time, count)

Convert an aggregated epidemic curve DataFrame into an ACSet. Requires Catlab.jl.

Outbreaks.aggregate — Function
aggregate(acset, scale; by=nothing)

Aggregate a line list ACSet by temporal/categorical scale. Returns a BucketedCases preserving fiber structure.

See also: decategorify, ↓

Outbreaks.decategorify — Function
decategorify(bucketed::BucketedCases) -> DataFrame

Count cases per bucket, collapsing categorical structure to counts. Information loss occurs here (not at binning).

See also: aggregate, ♯

Outbreaks.fibers — Function
fibers(bucketed::BucketedCases) -> Vector{DataFrame}

Return the preimage of each bin: the cases assigned to that bucket. This is the left Kan extension before applying cardinality.

Outbreaks.coarsen — Function
coarsen(bucketed::BucketedCases, new_scale::TemporalScale) -> BucketedCases

Compose binning functorially: if b buckets by week, coarsen(b, Month) computes Case → Week → Month without re-accessing raw data.

Outbreaks.aggregate_by — Function
aggregate_by(scale) -> Function

Curried form of aggregate for use with |> piping.

Example

ll |> aggregate_by(Week) |> ♯
Outbreaks.Class — Function

Create a CategoricalScale for school/hospital class.

Outbreaks.District — Function

Create a CategoricalScale for geographic district.

Outbreaks.Stratum — Function

Create a CategoricalScale for an arbitrary stratum.

Outbreaks.:↓ — Function
ll ↓ scale

Coarsen temporal resolution. Alias for aggregate. The downward arrow (↓) suggests information flows "down" to coarser scale.

Example

using Outbreaks, Catlab
ll = LineListACSet(measles_hagelloch_1861(), onset=:date_of_prodrome)
weekly = ll ↓ Week
monthly = weekly ↓ Month   # functorial composition
Outbreaks.♯ — Function
♯(bucketed)
♯(ll, scale)

Decategorify: count fibers. Alias for decategorify. The sharp (♯) evokes "counting measure" / discretization.

Example

♯(ll ↓ Week)           # weekly epidemic curve as DataFrame
♯(ll, Week)            # shorthand: aggregate + count in one step
♯(ll, Week ⊗ Class(:class))  # stratified counts
